Vectores de vectores

const int N = 3;
typedef int TipoVector[N];
TipoVector a;
TipoVector a, b, c;
typedef TipoVector TipoMatriz[N];   // un vector de vectores
TipoMatriz m;                       // m[0], m[1] y m[2] son vectores
typedef int TipoMatriz[N][N];       // lo mismo, escrito de una vez
TipoMatriz m;
typedef int TipoMatriz[N][N];
m[1][2] = 7;                        // fila 1, columna 2
typedef int TipoMatriz[N][N];
TipoMatriz m, n, p;
typedef TipoMatriz TipoCubo[N];     // un vector de matrices
TipoCubo c;                         // c[0], c[1] y c[2] son matrices
typedef int TipoCubo[N][N][N];      // lo mismo, escrito de una vez
c[capa][fila][col] = 7;
Empezamos por lo que ya conocéis: un vector de 3 enteros. Un tipo con typedef y una variable a de ese tipo.
Declaramos tres vectores: a, b y c. Tres variables sueltas, cada una con sus tres casillas.
Ahora metemos cada vector en una casilla de otro vector. Un vector puede guardar cualquier tipo, también vectores. Esto es m: un vector de 3 casillas donde cada casilla es un vector de 3 enteros. m[0] es un vector entero, igual que lo era a.
Si en lugar de dibujar las casillas de m en horizontal las dibujamos una debajo de otra, cada vector queda como una fila.
Quitamos los marcos y lo que queda es una matriz: filas y columnas. En C++ se escribe de una vez, con dos corchetes, y es exactamente lo mismo. El primer índice es la fila y el segundo la columna.
Para acceder a una celda: m[1] es la fila 1, que es un vector; y m[1][2] es la casilla 2 de ese vector. Se lee siempre fila y luego columna.
Y la idea se repite. Si tengo varias matrices de 3 por 3…
…puedo meterlas en un vector: c es un vector de matrices. c[0] es una matriz entera.
Si las apilo en profundidad, tengo un cubo: tres índices, capa, fila y columna. Se puede seguir añadiendo dimensiones tanto como haga falta, pero hoy nos quedamos en dos: matrices.

tadPatrones.cpp · ya hecho

void fila0 ( TipoMatriz &m, int color1, int color2 ) {
    int fila, col;

    for (fila = 0; fila < MAX; fila++)
        for (col = 0; col < MAX; col++)
            if (fila == 0)
                m[fila][col] = color1;
            else
                m[fila][col] = color2;
}

tadPatrones.cpp · los tienes que hacer tú

Recorre toda la matriz y decide el color de cada celda según su fila y su columna

El proyecto de hoy dibuja patrones en una rejilla de 9 por 9 con el entorno gráfico. La matriz es de enteros y cada número es un color; las constantes COLOR_NEGRO, COLOR_ROJO, etc. están en entornoMatriz.h. El programa principal llama a cada patrón y luego a pintarMatriz, que ya está hecho.
El único patrón que viene hecho es fila0. Para recorrer una matriz entera hacen falta dos bucles for anidados: el de fuera recorre las filas y el de dentro, las columnas de esa fila.
Y dentro, en cada celda, un if decide el color: si está en la fila 0, color1; si no, color2. Esa es toda la idea del ejercicio.
Tenéis que implementar los otros ocho en tadPatrones.cpp: damero, corona, diagonales, cruz, líneas horizontales y verticales y los dos triángulos. La especificación está en tadPatrones.h. Los dibujos son cómo los interpretamos: en las líneas, se alternan los colores; en diagonales van las dos; el triángulo superior izquierdo incluye la diagonal secundaria y el superior derecho, la principal.
La clave: todos son el mismo esquema que fila0, cambiando la condición del if. Pensad qué cumplen la fila y la columna de las celdas que van en color1. El programa los enseña todos seguidos, con un segundo de pausa entre uno y otro.
