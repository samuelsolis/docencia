Lo que ya conocen: una variable de tipo simple es una caja con un valor.
Si necesitamos las notas de 10 estudiantes: ¿10 variables sueltas? Con 1000 sería inviable, y no podríamos recorrerlas con un bucle.
Las agrupamos. Un vector es una estructura de datos que agrupa una colección de elementos, todos del mismo tipo, bajo un único nombre.
Este es el vector de ejemplo del guion: v, 10 elementos de tipo int. Cada caja guarda un int.
Para acceder a un elemento indicamos su posición: v[0], v[1], v[2]…
El primer elemento siempre ocupa la posición 0. Con 10 elementos, el último es v[9]. v[10] no existe: es el error típico, y normalmente el compilador no avisa.

El tamaño va en una constante. Si mañana son 5 estudiantes, se cambia en un solo sitio. Así está en lib_vector.h.
typedef define un tipo nuevo. Se lee: TipoVector es un vector de MAX celdas de tipo int.
Importante: esto no crea ninguna variable. Es el molde; todavía no hay ningún vector.
Con el molde definimos las variables que queramos, y también parámetros. Son tres vectores distintos con la misma estructura. Recién definidos no sabemos qué contienen: por eso las interrogaciones.

Con cada celda podemos hacer lo mismo que con un int. Asignar: v[0] pasa de 5 a 7.
Leer de teclado: el usuario escribe 12 y se guarda en v[3].
Escribir por pantalla: sale el valor de v[7], un 50.
Usar celdas en una condición: la primera parte es falsa, así que el if no se cumple.
Y lo más importante: el índice puede ser una variable. v[i] con i = 4 es v[4]. Eso es lo que nos permite recorrer un vector con un bucle.

Tentación: copiar un vector en otro con una asignación. No compila; este es el mensaje real de g++.
Con un int funciona porque es un dato simple. Un vector es una estructura: no hay asignación del vector completo.
El guion dice que ninguna es correcta, y es así. Pero hay un matiz: las dos últimas compilan, y no hacen lo que parece. Comprobado con g++ 9.4 y las opciones por defecto, sin ningún aviso: cout imprime la dirección de memoria, y v == w dio «distintos» con dos vectores de idéntico contenido. Es peor que un error de compilación, porque no os enteráis.
La solución: operar celda a celda, dentro de módulos que se comportan como esas operaciones. Ya los tenéis en lib_vector. Ojo con el orden en copiar: copia el primero en el segundo, así que v = w sería copiar(w, v). rellenar es una de las operaciones de hoy.

Inicializar: recorrer con un for

void iniciarAleatorio ( TipoVector &v, int maxValor ) {
    int i; // índice de 0 a MAX-1
    for ( i = 0; i < MAX; i++ ) {
        v[i] = rand() % ( maxValor + 1 ); // valores en [0, maxValor]
    }
}

Valores de ejemplo

Este módulo ya lo tenéis hecho en lib_vector.cpp. Es el esquema de casi todo lo de hoy: un for con i desde 0 hasta MAX-1, y en el cuerpo se trabaja con v[i]. El parámetro va por referencia, con &, porque el módulo modifica el vector.
Animación: i recorre las posiciones y cada celda recibe un valor en [0, 9], que es lo que da rand() % 10. Fijaos en el final: cuando i llega a 10, i < MAX es falso y el bucle acaba, sin tocar v[10]. Se usa sobre todo para agilizar las pruebas.

Sumar dos vectores: celda a celda

void sumarVectores ( TipoVector v, TipoVector w, TipoVector &suma ) {
    int i; // índice de 0 a MAX-1
    for ( i = 0; i < MAX; i++ ) {
        suma[i] = v[i] + w[i];
    }
}
i

Un solo índice i recorre los tres vectores

Valores de ejemplo

v es el vector que acabamos de iniciar; w, el de antes. suma aún no tiene valores. También está hecho en lib_vector.cpp. Solo suma lleva &, porque es el único que se modifica.
Animación: en cada vuelta se suman v[i] y w[i], y el resultado va a suma[i]. Las celdas de la misma posición se tratan juntas.
Idea para quedarse: con vectores del mismo tamaño, un único índice sirve para todos. Esto os sirve hoy para productoEscalar y dueloDeVectores. Y con esto pasamos a la práctica 8.
